# Hospital Data Analysis using Python

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of hospital data using Python to understand patterns and extract meaningful insights.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Understand and explore the dataset.
- Perform data cleaning and preprocessing.
- Identify patterns and trends.
- Perform statistical and visual analysis.
- Generate meaningful insights from the data.

## Analysis Performed
- Data exploration
- Data cleaning
- Univariate analysis
- Bivariate analysis
- Data visualization

## Conclusion
This project helped explore hospital data, identify patterns and understand how Python can be used for data analysis.
